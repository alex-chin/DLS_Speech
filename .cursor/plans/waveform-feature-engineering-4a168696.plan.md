## План по созданию новых фичей из raw waveform

### 1. Цели и ограничения
- **Цель**: повысить качество модели за счёт осмысленных признаков из временного сигнала, особенно улучшить recall для сложных классов (`dog`, `crying_baby`).
- **Ограничения**: используем только **raw waveform**, без перехода к MelSpectrogram или другим частотным представлениям в виде изображений.
- **Интеграция**: новые фичи будут использоваться либо как дополнительный вход в текущую модель (отдельная MLP‑ветка), либо для облегчённой модели только на признаках.

### 2. Пиковые признаки
- **2.1. Детекция локальных пиков**
  - Определить локальные максимумы/минимумы по сигналу или по огибающей (например, через порог по амплитуде и окрестности).
  - Отфильтровать «шумовые» пики (минимальное расстояние по времени, минимальная высота).
- **2.2. Признаки на основе пиков**
  - Среднее и медиана расстояний между соседними пиками.
  - Дисперсия расстояний между пиками.
  - Количество пиков в секунду.
  - Средняя/максимальная высота пиков и отношение высоты пиков к среднему уровню сигнала.

### 3. Энергетические и огибающие признаки
- **3.1. Окно и шаг**
  - Выбрать длину окна 20–50 мс и шаг 10–25 мс для вычисления энергетики.
- **3.2. Признаки по RMS/энергии**
  - RMS (или сумма квадратов) по каждому окну.
  - По всему клипу собрать: среднее RMS, максимум RMS, стандартное отклонение, коэффициент вариации (std/mean).
- **3.3. Динамика энергии (огибающая)**
  - Количество всплесков, когда RMS превышает заданный порог.
  - Средняя и медианная длительность всплеска.
  - Доля общей энергии, сосредоточенная во всплесках (энергия в «пиках» / суммарная энергия).

### 4. Периодичность и автокорреляция
- **4.1. Автокорреляция по окну**
  - Вычислить автокорреляцию по одному или нескольким окнам (например, центральное окно длительностью 200–500 мс).
- **4.2. Признаки периодичности**
  - Положение первого значимого пика автокорреляции (лаг с максимальным значением после нуля).
  - Отношение высоты этого пика к нулевому лага (нормализованная автокорреляция) — мера периодичности.
  - Количество заметных пиков автокорреляции выше порога.

### 5. Статистика формы сигнала и Zero‑Crossing Rate
- **5.1. Статистические моменты по амплитуде**
  - Среднее, стандартное отклонение.
  - Скос (skewness) и эксцесс (kurtosis) распределения амплитуд.
- **5.2. Zero‑Crossing Rate (ZCR)**
  - Вычислить ZCR по тем же коротким окнам.
  - Получить по клипу: средний ZCR, стандартное отклонение, минимум и максимум ZCR.

### 6. Многомасштабные time‑domain фильтры
- **6.1. Набор фиксированных фильтров**
  - Определить несколько линейных фильтров в временной области: низкочастотный, один‑два полосовых (с разными центральными частотами), высокочастотный.
- **6.2. Признаки по фильтрованным сигналам**
  - Для каждого фильтрованного сигнала повторить базовые энергетические и ZCR‑признаки (из разделов 3–5).
  - В результате получить набор признаков, чувствительных к разным диапазонам, оставаясь при этом в time‑domain.

### 7. Временная структура (сегментация клипа)
- **7.1. Разбиение по времени**
  - Разбить сигнал на K равных сегментов (например, K=3–5).
- **7.2. Агрегирование по сегментам**
  - Для каждого сегмента посчитать подмножество признаков (энергия, количество пиков, ZCR).
  - Затем агрегировать по сегментам: минимум, максимум, среднее, чтобы описать изменение звука во времени.

### 8. Интеграция фичей в модель
- **8.1. Отдельная MLP‑ветка для признаков**
  - Нормализовать признаки (например, стандартизация по train‑сету).
  - Пропустить вектор фичей через небольшой MLP (1–2 полносвязных слоя с ReLU и Dropout).
- **8.2. Объединение с 1D‑CNN по waveform**
  - В выходном слое CNN (после глобального pooling) конкатенировать CNN‑вектор и вектор фичей.
  - Передать конкатенированный вектор в финальный классификатор (1–2 слоя).

### 9. Минимально необходимый список признаков
- **Базовый набор (10–20 штук)**:
  - Средний, максимум и std RMS по клипу.
  - Количество всплесков энергии и их средняя длительность.
  - Средний и std ZCR.
  - Среднее расстояние между пиками и его std.
  - Скос и эксцесс амплитуд.
  - Нормализованный основной лаг автокорреляции и высота пика.
  - 2–4 признака, полученные после фильтрации (например, энергия в низкочастотном и высокочастотном каналах).

### 10. Протокол оценки вклада признаков
- **10.1. Базовая линия**: текущая модель на чистом waveform.
- **10.2. Модель только на признаках**: простой MLP на векторе фичей → оценка их силы.
- **10.3. Комбинированная модель**: 1D‑CNN + признаки.
- Сравнивать по **macro‑F1** и per‑class recall, особенно для `dog` и `crying_baby`.
